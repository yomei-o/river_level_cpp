川の水面を y 座標で測る

善福寺川・石神井川のライブカメラの録画から、水面の y 座標を 7 通りの方法で求めます。計算は C++ を WebAssembly にしたもので、ブラウザの中だけで動きます。

読み込み中…

白い点線が解析する範囲（ROI）です。画像をドラッグすると範囲を描き直せます。Shift を押しながらクリックすると、その x を水位標の列（方法 F）にします。
